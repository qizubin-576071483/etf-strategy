⚡ 更新价格与得分

本页面是纯静态站点，无法在浏览器里直接改服务器数据。
请用下面任一方式触发更新。
🚀 在 GitHub 上一键运行 查看最近一次运行结果 📋 复制任务链接（按钮打不开时用）
方式一：网页点击（推荐，手机也能用）
  1. 点上方按钮，登录 GitHub
  2. 右上角点 Run workflow → 再点绿色 Run workflow
  3. 约 1 分钟后刷新策略页即可看到新数据
方式二：电脑本地双击（最快，不走排队）
  1. 双击项目目录里的 手动更新价格.bat
  2. 脚本会抓最新价、重算全部得分并直接推上线
  3. 十几秒完成，无需等待云端构建
自动更新：每个交易日 15:00（北京时间）自动运行
费用：GitHub Pages + Actions，公开仓库完全免费，无次数限制
周末与节假日休市，脚本会自动跳过，不会产生重复数据。
